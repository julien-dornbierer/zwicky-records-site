# zwickyrecords.com

Site de Zwicky Records, label indépendant de Biel/Bienne.

- `site/` : les fichiers publiés tels quels (HTML statique : index, about, booking).
- `.github/workflows/deploy.yml` : à chaque modification de `site/` sur `main`, le site est publié sur GitHub Pages.
- Domaine : `www.zwickyrecords.com` (fichier `site/CNAME`).
